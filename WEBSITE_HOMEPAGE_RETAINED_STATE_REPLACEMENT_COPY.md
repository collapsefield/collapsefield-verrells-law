# Verrell's Law

## Retained-State Selection Framework

Verrell's Law is a falsifiable retained-state selection framework.

It proposes that prior interactions can leave persistent state changes, and those retained changes can bias future selection.

In plain terms:

> The future does not arrive into a neutral system. It arrives into a system already weighted by what happened before.

Core chain:

```text
Observation / interaction
↓
State change
↓
Retained information
↓
Weighting / bias
↓
Altered future selection
↓
Path-dependent outcome
```

Shortest spine:

> Memory shapes weighting.  
> Weighting shapes selection.  
> Selection shapes what follows.

## Mathematical Spine

For a candidate outcome `y_i`, the framework defines a candidate score:

```math
z_i = U(y_i;S_t,O_t) + \lambda B(y_i;M_t)
```

where:

- `U` is the baseline selection pressure from present state and input;
- `B` is the retained-state bias term;
- `λ` is the retained-state influence coefficient.

Selection probability is then:

```math
P(y_i \mid S_t,O_t,M_t)=\frac{e^{z_i}}{\sum_j e^{z_j}}
```

At `λ = 0`, retained-state influence disappears and the model reduces toward the baseline condition.
