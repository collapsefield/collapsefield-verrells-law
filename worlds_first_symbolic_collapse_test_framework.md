This project presents an early symbolic collapse test framework using structured JSON cue logic.

It was designed as a proof-of-concept for testing how weighted symbolic cues, observer input, and retained contextual structures may influence selection outcomes inside a controlled digital framework.

The system explored early versions of ideas now formalised more clearly inside Verrell’s Law and Collapse Aware AI, including:

- symbolic cue weighting

- emergence loops
- collapse-aware behavioural logic
- structured JSON-based test states

This framework should be understood as an early experimental layer, not the final form of Verrell’s Law or Collapse Aware AI.

## Purpose

The purpose of the framework was to test whether structured symbolic inputs could be used to model a simple form of collapse-like selection.

Instead of treating outputs as purely static or random, the system introduced weighted cue structures that could be adjusted, interpreted, and compared across repeated trials.

This allowed early exploration of whether symbolic memory, cue salience, and observer input could shape outcome selection in a measurable digital environment.
