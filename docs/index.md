# Verrell’s Law — Official Clarification

**Scope updated: 4 November 2026.** Earlier wording on this page identified electromagnetic field memory as the foundation. That is preserved in Git history as an earlier exploratory interpretation, **not** the present core claim.

## Core statement

Verrell's Law is a falsifiable retained-state selection research framework. Previous interactions can leave persistent state changes; retained information may alter later weighting and selection under otherwise matched present conditions. This does not require an electromagnetic memory field or a quantum collapse mechanism. Field-mediated and quantum hypotheses remain separate exploratory research branches.

This is distinct from Rupert Sheldrake's morphic resonance. The current framework does not postulate a universal memory field, non-local personal memory storage or supernatural transmission.

The scientific programme demands explicit retained-state variables, matched present conditions, independently frozen weighting scores, intervention and held-out predictions compared with conventional mechanisms. The exponential-tilt identity is mathematically exact within its defined model, not independent experimental proof.

## Research boundaries

- **Biology:** neurophysiological memory mechanisms can provide retained state without postulating external storage.
- **Software:** recorded state can shape governed selection, but software conformance does not verify a natural law.
- **Fields and quantum models:** optional, exploratory research that must meet separate measurement and physical-consistency requirements.
