## 1. Summary

This note records a core timing claim inside Verrell's Law:

> Time is not treated as a fundamental flow. It is treated as the measurement layer placed over ordered change.

In this framing, reality does not move through time as though time were a substance, container, or external river. Instead, reality updates through ordered state transitions, or **frames**. Human observers measure the spacing, ordering, and continuity of those frames and call that measurement **time**.

Short form:

```text
Time is not the engine.
Time is the readout.
```

This note does not claim to solve the physics of time. It defines the working interpretation used inside Verrell's Law so that later work on observation, measurement, collapse-like selection, and memory-weighted prior state has a stable reference point.

## 2. Core Position

Verrell's Law treats change, observation, and selection as more fundamental than clock-time.

The central claim is:

```text
fundamental process = change / selection / frame transition
human abstraction = time
```

A cleaner formulation:

> Reality does not move through time. Reality updates through frame succession. Humans measure the spacing and ordering of those updates and call that measurement time.

This means that what humans experience as temporal flow may be produced by stacked observation frames:

```text
frame -> retained structure -> biased selection -> next frame
```

Not:

```text
time -> event -> time -> event
```

In this model, time is not denied. The claim is narrower and more precise: time is not the primary actor. It is the ordered measurement of observed change.

## 3. Change Without Fundamental Linear Time

Change does not require a pre-existing linear time axis.

It requires ordered difference.

At minimum, change requires:

```text
state A != state B
and
some relation by which B is after, derived from, selected after, or ordered relative to A
```

If there is no ordering of any kind, then change cannot meaningfully occur.

However, if there is ordered state differentiation, then linear clock-time is not required as a fundamental substrate. The appearance of time can emerge from the ordering of changes.

Short form:

```text
Linear time is not necessary for change.
Ordered difference is.
```

## 4. Frame Succession

A **frame** is an observed or selected state boundary.

A frame is not necessarily a literal visual image. It is a state condition that has become coherent enough to be treated as the current present.

A simple sequence:

```text
possible states
-> observation / interaction / constraint
-> collapse-like selection
-> present frame
-> retained trace
-> next selection
```

The present is therefore not a passive point on a timeline. It is an active selection boundary.

The selected frame becomes part of the retained structure that biases later frames.

This creates the basic Verrell's Law loop:

```text
present frame emerges
-> frame becomes retained memory
-> retained memory biases next selection
-> next frame emerges
```

This loop is what human observers experience as time.

## 5. Measurement and Observation

Measurement is central because measurement converts change into ordered reference.

Without observation, interaction, or comparison, there is no usable time measurement.

A clock does not discover a flowing substance called time. A clock counts regular changes and provides a reference against which other changes can be ordered.

Therefore:

```text
clock-time = calibrated comparison of change
observed time = ordered experience of frame transition
physical time = modelled structure used to coordinate events
```

Verrell's Law is most concerned with the second and third layers: observed frame transition and the modelled ordering of events.

This creates the measurement link:

```text
change occurs
observation detects difference
measurement orders the difference
time is inferred from the ordered difference
```

The key point:

> Measurement does not simply sit inside time. Measurement helps construct the usable ordering that observers call time.

## 6. Observation as Frame Boundary

Observation is treated as a boundary condition.

Observation does not necessarily mean human visual awareness. It can mean any interaction that constrains possibilities into a more definite state.

In a Verrell's Law framing:

```text
unresolved possibility field
+ observation / interaction / constraint
+ prior retained structure
= selected present frame
```

Once selected, the frame becomes part of history. But history is not inert. It becomes retained structure.

That retained structure can then re-enter future selection as bias:

```text
selected frame -> retained trace -> future bias term
```

This is the bridge between time, memory, and measurement.

## 7. Memory-Weighted Frame Selection

Verrell's Law proposes that retained information from prior states may alter the probability landscape of future outcomes.

Applied to time:

```text
past frame information
+ present observation
+ field / system conditions
= biased selection of next frame
```

This means the past does not merely sit behind the present as a completed sequence.

It can re-enter the present as active residue:

```text
past does not vanish
past loops forward into present as retained bias
present selection is therefore not neutral
future probability is shaped by memory-weighted prior state
```

The present is not only caused by the past. It is selected through the active residue of the past.

## 8. Relation to Linear Time

Linear time is useful as a measurement convention.

It is useful for:

- clocks
- calendars
- physics equations
- engineering systems
- historical records
- causal mapping
- human coordination

But usefulness does not prove fundamentality.

A ruler can measure distance without being the cause of space. A clock can measure ordered change without being the cause of change.

In this note, linear time is treated as:

```text
a modelling tool for ordering observed change
```

Not:

```text
the fundamental substance through which reality moves
```
