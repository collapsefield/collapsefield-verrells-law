# Retained-State Selection — Cross-Domain Worked Examples v0.1

**Status:** Conceptual / analytical examples; non-canonical  
**Date:** 30 August 2026  
**Author / originator:** Marcos Verrell Moss Ross (M.R.)  
**Research attribution refresh:** 14 September 2026

---

## Purpose

Retained-State Selection is a substrate-neutral way to ask:

> **When the present decision surface is held sufficiently similar, does preserved information from earlier states influence which later candidate outcome is selected?**

The same abstract question can be instantiated in many fields without implying that every field shares one mechanism.

A legal precedent, robot action history, software memory record, synaptic change and material hysteresis state are not physically identical simply because each can create path dependence.

The value of the framework is to make the **retention → influence → selection** relationship explicit enough to compare and test.

---

## 1. AI agents

An agent reaches the same present task with several permitted actions, for example:

```text
A — retry current tool
B — switch to fallback
C — ask for clarification
```

Two runs share the same present task and permissions but carry different prior tool histories.

Test whether history changes candidate-relative preference while the permitted-action boundary remains fixed.

If the system was deliberately engineered so its internal retained-state score drives selection, the result is primarily **engineering conformance**.

---

## 2. Robotics

History-aware candidate verification is an adjacent engineering pattern: multiple candidate actions are proposed and previous interactions help select among them.

This is genuine history-conditioned candidate selection, but it is not by itself validation of Verrell’s Law or proof that every implementation uses the same mechanism.

---

## 3. Runtime AI governance

A runtime may evaluate the same proposed action differently depending on the path that led to it.

Retained-State Selection is adjacent but asks a narrower question where **multiple actions remain permitted**:

> Which permitted action should win given the relevant retained path/state?

Policy and permission remain separate from retained-state influence.

---

## 4. Regulated customer operations

A collections, vulnerability, fraud or case-handling workflow may have several permitted interventions:

```text
A — digital message
B — human call
C — request information
D — hold / wait
E — specialist escalation
```

Two cases may look similar now but carry different failed-contact, vulnerability, arrangement or previous-response histories.

The retained-state question is which parts of that history should alter relative selection among the permitted interventions.

The framework does not decide what is lawful or regulator-approved. Policy defines the candidate boundary first.

---

## 5. Adaptive training / simulation

Two learners reach the same scenario state but have different retained learning histories.

With an authored candidate set such as repeat, increase difficulty, surface corrective coaching or move on, the test is whether different prior performance changes the governed next-event selection under matched present conditions.

This domain is attractive experimentally because candidate branches, present state, history manipulation, replay and intervention can all be controlled.

---

## 6. Games / NPC behaviour

An NPC may have a bounded authored action set while player/NPC history differs across otherwise matched world states.

The retained-state selector may influence which authored action wins while the host game remains authoritative for identity, world truth, permissions and execution.

This demonstrates the distinction between **history-sensitive selection** and inventing unrestricted world state or actions.

---

## 7. Institutional / legal path dependence

Precedent, prior enforcement, contractual state, commitments and organisational learning are familiar forms of path dependence.

They can be modelled as retained information influencing later choice, but this is an analytical analogy unless a specific measurable test is defined. It is not evidence that institutions literally implement a new physical mechanism.

---

## 8. Cognition and human behaviour

Learning, memory, conditioning, adaptation, expectation, habit and neural plasticity are established forms of history dependence.

A stronger Verrell’s Law test would require:

1. matched present stimulus/task;
2. declared retained-history manipulation;
3. preregistered candidate-relative prediction;
4. defensible retained-state measure or proxy;
5. held-out prediction;
6. intervention / ablation where possible;
7. conventional cognitive and neural confounds controlled.

The scientific contribution would come from the specific predictive structure, not from rediscovering that people have memories.

---

## 9. Biological systems

Biological systems retain history through known structural, chemical, epigenetic, neural and regulatory mechanisms.

A retained-state experiment could ask whether otherwise matched systems with controlled different histories select different later responses.

Known biology must be modelled first. A residual effect is not automatically evidence for an unknown field.

---

## 10. Materials / hysteresis

Hysteresis is an established form of physical history dependence and is not claimed as a discovery of Verrell’s Law.

It provides a useful comparator:

```text
same nominal present input
+ different retained physical state
→ different response
```

A Verrell-specific model would need to add predictive value beyond the established material model.

---

## 11. Unknown physical / biosignal mechanisms

A future research programme may test whether an unmeasured physical or biological channel participates in retained-state influence.

The correct sequence is:

```text
reproducible residual effect
→ known confounds controlled
→ measurement sensitivity established
→ mechanism candidates compared
→ new detector/channel only if justified
```

Not:

```text
no detected effect
→ assume an undetectable mechanism exists
```

---

## Turning an analogy into a test

A cross-domain analogy becomes scientifically useful only when the following are declared:

1. **Present state** — what is held matched?
2. **Retained state** — what historical variable differs?
3. **Candidate set** — what outcomes are compared?
4. **Observable** — what is measured?
5. **Prediction** — what direction or magnitude is expected?
6. **Baseline** — what happens without the retained-state difference?
7. **Intervention** — can retained state be changed or ablated?
8. **Evidence class** — engineering conformance, independent empirical, proxy-based or exploratory?

Without those steps, retained-state selection is only a metaphor. With them, it becomes a testable modelling framework.
