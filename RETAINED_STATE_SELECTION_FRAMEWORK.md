# Retained-State Selection Framework

**Author / originator:** Marcos Verrell Moss Ross (M.R.)  
**Status:** Current public conceptual framework  
**Updated:** 14 September 2026

---

## Core claim

Verrell's Law is currently presented as a **retained-state selection framework**, not as an established law of physics.

> Prior interactions can leave persistent state changes. Those retained changes may influence later selection, producing path-dependent divergence under otherwise matched present conditions.

Shortest form:

> Memory shapes weighting.  
> Weighting shapes selection.  
> Selection shapes what follows.

---

## Claim boundary

The framework does not require or establish:

- a universal electromagnetic memory field;
- consciousness as a universal selection mechanism;
- consciousness-caused quantum collapse;
- modification of general relativity;
- a new fundamental force;
- software behaviour as proof of new physics.

Possible biological or physical mechanisms remain separate empirical questions.

---

## What is being tested

The research contribution is not invention of memory, softmax, logits, Bayesian updating, reinforcement learning, hysteresis, Markov processes or state-dependent dynamics.

The narrower question is whether retained history can be represented as an explicit, measurable candidate-relative influence and tested through controlled comparison, held-out prediction and intervention.

```text
Observation / interaction
↓
State change
↓
Retained information
↓
Weighting / influence
↓
Altered later selection
↓
Path-dependent outcome
```

---

## Operational state boundary

Let:

- `S_t` = present system variables held matched by the test protocol;
- `O_t` = present observation / input;
- `M_t` = retained-history variables deliberately varied, ablated or compared;
- `y_i` = candidate outcome / action / interpretation.

The `S_t` / `M_t` boundary is operational, not metaphysical. Real current state may already contain traces of history; the experiment must declare what is controlled as present state and what is varied as retained history.

---

## Illustrative selection form

A useful general form is:

```math
z_i = U(y_i;S_t,O_t)+\lambda B(y_i;M_t)
```

with:

```math
P(y_i\mid S_t,O_t,M_t)=\frac{e^{z_i}}{\sum_j e^{z_j}}
```

or deterministic selection:

```math
y^*=\arg\max_i z_i
```

This mathematics is standard. The research claim concerns identification and testability of the retained-state contribution, not novelty of the selection equation.

---

## Identifiability constraint

Only the combined retained-state contribution enters the candidate score. Therefore coupling strength and retained-state score are not separately meaningful unless the scoring convention and scale are fixed.

A valid confirmatory test should predeclare:

1. present-state matching criteria;
2. retained-history conditions;
3. candidate set;
4. retained-state feature / score rule;
5. baseline or ablated condition;
6. analysis procedure;
7. known confounds;
8. decision rule for support or failure.

For current empirical identification, use the canonical mathematical specification and empirical-identification clarification.

---

## Falsifiable pattern

The basic test is:

```text
same present condition
+ same candidate set
+ different retained history
→ measure later selection difference
```

Then intervene:

```text
disable / erase / scramble retained-state influence
→ test whether the predicted difference reduces or disappears
```

If the preregistered relationship fails under adequate controls, the framework is not supported in that tested regime.
