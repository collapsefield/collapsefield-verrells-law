# Archived Document Status

## Purpose

This repository preserves the public development trail for Verrell’s Law.

Some files contain earlier exploratory wording, stronger speculative language, older mathematical attempts, or provisional field-memory terminology. These documents are intentionally preserved for authorship, provenance, and research-continuity reasons.

They should not be read as hidden, deleted, or abandoned material. They are part of the public record showing how the framework developed over time.

---

## Current Public Framing

The current preferred framing of Verrell’s Law is:

> Verrell’s Law is a retained-state selection framework proposing that prior interaction can leave persistent state changes which influence future selection, interpretation, memory, and behaviour.

The current engineering boundary is:

> Collapse Aware AI is classical middleware for governed retained-state behavioural selection. It does not require proof of quantum collapse, non-local memory storage, or machine consciousness in order to be evaluated as software.

## Scientific Boundary

Verrell’s Law does not currently claim:

- completed experimental proof
- established new physics
- proof that consciousness collapses the wavefunction
- proof that memory exists only outside the brain
- proof that current AI systems are conscious
- proof that Collapse Aware AI validates the full physical framework

The current claim is narrower:

> retained history can act as a measurable weighting influence on future selection, producing path-dependent divergence under controlled conditions.

That claim remains open to testing, refinement, reduction, or falsification.

---

## Archive Principle

The archive is kept transparent by design.

Older documents are not removed simply because the framework has matured. Instead, notes are added where needed so readers can see which materials are current, which are historical, and which remain speculative.

This protects the authorship trail while keeping the public interpretation disciplined and technically bounded.
