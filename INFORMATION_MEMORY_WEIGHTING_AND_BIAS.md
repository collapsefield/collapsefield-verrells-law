# Information, Memory, Weighting and Bias

## Core Hierarchy

Information → Memory → Weighting → Bias → Selection → Outcome

This hierarchy describes how retained information can influence future system behaviour.

## Definitions

### Information
Information is any state, signal, pattern, observation, measurement, or record capable of reducing uncertainty.

### Memory
Memory is retained information capable of influencing future state.

### Weighting
Weighting is the assignment of relative importance to retained information.

### Bias
Bias is directional weighting.

Within this framework, bias does not automatically imply error. It simply means that some possibilities are weighted differently from others.

### Selection
Selection is the process by which one candidate state, action, interpretation, or output becomes preferred over alternatives.

### Outcome
An outcome is the realised result of a selection process.

## Observable Examples

- Neural-network weights
- Bayesian priors
- Human preferences
- Database records
- Learned behaviours
- Evolutionary selection pressures

All demonstrate retained information influencing future decisions.

## Position Statement

Verrell's Law investigates whether retained information can be treated as a meaningful selection-bias term across different classes of systems.

The engineering implementation of this principle appears within Collapse Aware AI through memory weighting, continuity management, and governor-constrained behavioural selection.
