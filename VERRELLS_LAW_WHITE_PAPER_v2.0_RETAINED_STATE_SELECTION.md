## Abstract

Verrell's Law proposes that system evolution is not determined by present input alone. It argues that prior interaction can leave retained state, and that retained state can act as a directional weighting influence over future selection.

In its current form, Verrell's Law does not require memory to be stored as a non-local field, nor does it depend on any completed claim about quantum collapse, consciousness physics, or universal electromagnetic memory. Instead, it is framed as a testable retained-state selection framework:

> Systems with different retained histories may not evolve toward the same future state, even when present input is held constant.

The central claim is that retained information can function as an active weighting term in selection dynamics. This can be studied across computational systems, biological systems, cognitive systems, artificial intelligence, symbolic systems, and potentially physical systems, while recognising that the mechanisms may differ between domains.

Collapse Aware AI (CAAI) is the engineering branch of this work. It applies the retained-state selection principle as governed middleware for behavioural continuity, memory-weighted influence, and controlled final-action selection. CAAI does not require the full scientific scope of Verrell's Law to be proven in order to be evaluated as software.

This white paper defines the current public version of Verrell's Law, its mathematical spine, its claim boundaries, its relationship to existing work, and its proposed routes for falsification.

## 1. Core Statement

Verrell's Law can be stated as follows:

> Retained state from prior interactions can influence future selection by acting as a memory-derived weighting term, producing path-dependent divergence between systems that otherwise share the same present input.

Simplified:

~~~text
Prior interaction
        ↓
State change
        ↓
Retained information
        ↓
Memory-derived weighting
        ↓
Biased future selection
        ↓
Path-dependent outcome
~~~

Plain version:

> The future does not arrive into a neutral system. It arrives into a system already weighted by what has happened before.

This is the current foundation of the law.

## 2. What Has Changed From Earlier Versions

Earlier versions of Verrell's Law placed heavier emphasis on resonance, electromagnetic fields, non-local information, and consciousness-collapse interpretations.

Those remain possible future research directions, but they are no longer required for the core claim.

The current version is deliberately narrower:

- memory does not need to be external to the brain or system
- information does not need to be a separate substance
- electromagnetic fields may participate in some systems, but are not required universal carriers
- consciousness is not required to explain every retained-state effect
- Collapse Aware AI does not depend on proving consciousness physics
- the core claim must be testable through measurable divergence

This makes Verrell's Law stronger, not weaker.

The law now begins with retained state because retained state is observable, modelable, and testable across many domains.

## 3. Key Definitions

### 3.1 Observation / Interaction

Observation does not mean mystical consciousness.

In this framework, observation can mean:

- measurement
- contact
- input
- attention
- perception
- environmental interaction
- computational update
- state registration
- feedback from a prior event

The important point is that interaction changes the system in some way.

### 3.2 Retained State

Retained state means any prior change that persists long enough to influence later behaviour.

Examples include:

- memory traces in cognition
- weights in machine learning
- hidden state in recurrent systems
- cached state in software
- emotional salience in human memory
- biological adaptation
- physical hysteresis
- path-dependent material response
- behavioural anchors in an AI agent

Retained state is the bridge between past interaction and future selection.

### 3.3 Memory-Derived Bias

Bias does not automatically mean error.

In Verrell's Law, bias means directional weighting.

A retained history can make one future outcome more likely than another. This may produce useful continuity, harmful distortion, adaptive learning, false recall, stabilised identity, or behavioural drift depending on the system.

### 3.4 Selection

Selection means the resolution of multiple possible outcomes into one expressed outcome.

In different systems, selection may appear as:

- a chosen behaviour
- a recalled memory
- a generated response
- a physical transition
- a biological adaptation
- an action
- a decision
- a collapsed state in a probabilistic model

Verrell's Law studies how retained state affects that selection.

## 4. Mathematical Spine

The current public mathematical framing uses a memory-weighted selection equation.

Let:

- $y_i$ = candidate outcome, behaviour, interpretation, or future state
- $S_t$ = present system state
- $O_t$ = present observation or input
- $M_t$ = retained memory / state history
- $U(y_i; S_t, O_t)$ = present-state utility or baseline selection value
- $B(y_i; M_t)$ = memory-derived bias term
- $\lambda$ = memory-bias coupling strength

Then:

$$
P(y_i \mid S_t, O_t, M_t)
=
\frac{
\exp\left(U(y_i; S_t, O_t) + \lambda B(y_i; M_t)\right)
}{
\sum_j \exp\left(U(y_j; S_t, O_t) + \lambda B(y_j; M_t)\right)
}
$$

This equation does not claim that softmax, Bayesian selection, reinforcement learning, or probabilistic modelling are new.

The claim is narrower:

> Retained history can be explicitly modelled as an active bias term in future selection.

If $\lambda = 0$, the memory-derived bias disappears and the model reduces to present-state selection.

If $\lambda \neq 0$, retained state can alter future selection probability.

## 5. Path-Dependent Divergence

The central falsifiable prediction is that two systems with the same present input but different retained histories may diverge in future selection.

Let two systems share the same current state and input but differ in memory history:

~~~text
System A:  S_t, O_t, M_t^A
System B:  S_t, O_t, M_t^B
~~~

Then:

$$
\Delta P(y_i) \propto \lambda \cdot \left[B(y_i; M_t^A) - B(y_i; M_t^B)\right]
$$

If retained history matters, systems A and B should show measurable divergence.

If no repeatable divergence appears under controlled conditions, then the Active Information Weight claim fails in that regime.

That is the falsifiability spine.

## 6. Active Information Weight

Active Information Weight (AIW) is the measurable influence of retained prior information on future selection probability.

AIW does not mean all remembered information is active.

Information becomes active only when retained state affects future selection.

In simple terms:

~~~text
stored information = information that exists in the system
active information = information that changes future selection
~~~

This distinction matters.

A system can store vast amounts of data without that data shaping behaviour. Conversely, a small retained state can have strong influence if it becomes highly weighted.

## 7. Weighted Emergence Layering

Weighted Emergence Layering (WEL) describes how retained information can become structured influence over time.

Rather than treating emergence as a single jump from simplicity to complexity, WEL treats emergence as layered accumulation:

~~~text
retained state
        ↓
weighted influence
        ↓
selection bias
        ↓
repeated feedback
        ↓
structured behavioural pattern
        ↓
emergent continuity
~~~

In biological systems, this may appear as learning, habit, emotional patterning, or identity continuity.

In AI systems, this may appear as persistent character behaviour, agent stability, reduced drift, or memory-weighted final-action selection.

In physical systems, it may appear as hysteresis, threshold shifts, state-dependent response, or path-dependent material behaviour.

The mechanisms differ. The retained-state structure is the common research pattern.

### 7.1 Evidence Boundary — Collapse Aware AI

The two stages of this layering have different evidence status, and the distinction must be preserved in any public or buyer-facing material.

**Single-step layering — built / Phase-1 evidence tier**

This refers to retained state biasing a single governed selection:

~~~text
same candidate set
same present input
different retained history
different selected behaviour
Governor constraints applied
diagnostic evidence available
~~~

This is the current Gold Build Core proof direction.

**Recursive / emergent layering — specified / roadmap tier**

This refers to the wider loop in which selected behaviour updates retained state and reshapes later selection across repeated cycles:

~~~text
selected behaviour
        ↓
updated retained state
        ↓
later selection bias
        ↓
repeated continuity
~~~

Unless separately implemented and verified, recursive / emergent WEL must be treated as roadmap, not as a present Phase-1 capability.

Public materials should not imply that the recursive or emergent layer is already present in Phase-1.

## 8. Relationship to Memory Science

Verrell's Law is compatible with the view that memory is reconstructive.

Human memory is not a perfect replay device. It is rebuilt through stored traces, present context, emotional salience, prediction, and interpretation. This is visible in false memories, memory distortion, source-monitoring errors, and reconsolidation effects.

Relevant adjacent work includes:

- Frederic Bartlett's work on reconstructive memory
- Elizabeth Loftus's work on memory malleability and false memory
- memory reconsolidation research showing that recalled memories can become labile and changeable
- predictive-processing models in which perception and recall are shaped by prior expectation
- active inference and free-energy approaches in which organisms act to reduce uncertainty through predictive state updating

Verrell's Law does not replace those traditions.

It reframes the shared pattern:

> Memory is not passive storage alone. It is retained state that can weight future interpretation and selection.

## 9. Relationship to Artificial Intelligence

Modern AI systems increasingly face the problem of continuity.

A model may produce strong outputs in isolation but still fail to maintain stable behaviour over time.

Common failure modes include:

- forgetting prior context
- drifting from role or objective
- contradicting earlier commitments
- over-weighting recent input
- under-weighting important history
- unstable agent identity
- inconsistent refusal behaviour
- uncontrolled behavioural loops
- context-window dependence

Verrell's Law is relevant because it asks:

> How should retained state influence future selection?

This question is not solved by storage alone.

A memory database can retrieve information, but retrieval is not the same as governed influence.

The deeper issue is behavioural selection:

- What was retained?
- How strongly should it matter?
- When should it be ignored?
- When should it stabilise behaviour?
- When should it be overridden?
- How do we prevent drift?
- How do we expose the decision path?

This is where Collapse Aware AI sits.

## 11. Relationship to Existing Work

Verrell's Law sits near several existing research traditions but is not identical to any one of them.

### 11.1 Reconstructive Memory

Bartlett and Loftus showed that memory can be reconstructed, distorted, and shaped by context.

Verrell's Law extends this into a general retained-state selection framing:

> what is retained can bias what is later selected, remembered, interpreted, or expressed.

### 11.2 Predictive Processing and Active Inference

Predictive-processing and active-inference models treat cognition as expectation-guided interpretation and action.

Verrell's Law is compatible with this direction because retained priors can be understood as weighting future interpretation.

The distinction is that Verrell's Law frames this as a wider selection principle across cognitive, computational, symbolic, and potentially physical systems.

### 11.3 Reinforcement Learning and Control Theory

Reinforcement learning already models how prior reward histories affect future action selection. Control theory studies feedback, stability, error correction, and regulation.

Verrell's Law does not claim to invent these ideas.

Its narrower contribution is to formalise retained informational history as an active weighting influence and to place memory-derived bias at the centre of path-dependent selection.

### 11.4 Dynamical Systems and Path Dependence

Many systems are history-dependent.

Examples include:

- hysteresis
- attractor dynamics
- feedback loops
- turbulence
- ecological adaptation
- market behaviour
- neural plasticity
- identity formation
- software state machines

Verrell's Law belongs naturally in this family of ideas.

Its specific focus is the role of retained state as an active selector of future outcomes.

### 11.5 Electromagnetic and Field Theories of Consciousness

Theories such as Pockett's electromagnetic field hypothesis and McFadden's CEMI theory explore whether electromagnetic activity plays a role in consciousness.

Verrell's Law remains open to the possibility that electromagnetic fields participate in biological cognition or other retained-state systems.

However, the current public version does not require EM fields as the universal memory carrier.

The safer position is:

> Electromagnetic fields may be relevant in some substrates, especially biological and measurement systems, but Verrell's Law is not dependent on non-local electromagnetic memory storage.

This protects the core law from being tied to a speculative physical mechanism before evidence is sufficient.

### 11.6 Quantum Cognition

Quantum cognition uses mathematical structures from quantum theory to model decision-making, context effects, and probabilistic cognition.

Verrell's Law is compatible with some quantum-cognition themes, especially where present selection depends on context, prior state, and probability weighting.

This does not mean Verrell's Law claims that the brain literally performs quantum collapse during ordinary thought.

The useful bridge is structural:

> context and retained history can change selection probability.

## 13. Testability

Verrell's Law is falsifiable if framed correctly.

A proper test should compare systems where present input is held constant but retained history differs.

Basic test pattern:

~~~text
Condition A:
    same present input
    history A

Condition B:
    same present input
    history B

Measure:
    difference in future selection probability
~~~

If history has no measurable effect, then $\lambda$ should collapse toward zero.

If history has measurable influence, then $\lambda$ should be recoverable from selection data.

- recency decay

The expected result is not random variation.

The expected result is controlled divergence:

~~~text
same present input
different retained history

measurable selection shift
~~~

This is where CAAI Gold Build Core becomes relevant as an engineering testbed.

## 15. Cognitive Test Route

A psychological version could test whether prior memory conditioning alters later interpretation under controlled present input.

Possible designs include:

- ambiguous stimulus interpretation after different memory-priming histories
- false-memory formation after post-event information
- source-monitoring tests
- emotional salience weighting
- recall reconstruction after delayed reconsolidation
- repeated choice tasks with controlled prior histories

The measured output would be whether retained prior context predictably biases later selection or interpretation.

---

## 16. Physical Test Route

Physical tests remain possible but should be treated as future research.

Potential areas include:

- hysteresis and retained-state material response
- optical threshold shifts after prior interaction
- interference experiments with strict controls
- quantum random number generator studies
- photonic or phononic systems where prior state affects later distribution

Any physical claim must meet a high standard.

The items above are illustrative future directions, not reported results. No physical experiment is claimed here to have been performed or to have returned a positive outcome, and no new physics is asserted.

The current public position is deliberately cautious:

> Physical systems may provide retained-state examples, but no completed claim of new physics is made here.

---

## 17. Falsification Conditions

Verrell's Law fails in a given regime if:

- present input is controlled
- retained history is varied
- measurement is properly blinded
- enough trials are run
- no repeatable divergence appears
- $\lambda$ cannot be recovered above noise
- simpler baseline models explain the results fully

This is important.

A framework that cannot fail is not useful science.

Verrell's Law must remain testable, reducible, and vulnerable to evidence.

## 18. Why the Law Matters

Verrell's Law matters because many systems are still treated too much like present-input machines.

But living systems, cognitive systems, social systems, AI agents, and adaptive software systems do not operate from neutral present states.

They operate from retained histories.

That matters for:

- memory
- identity
- learning
- behaviour
- agency
- AI alignment
- simulation
- NPC continuity
- long-running agents
- decision systems
- interpretability
- drift control
- scientific models of path dependence

The law provides a common language for the same underlying pattern:

> The past remains active when it changes the state from which the future is selected.

## 19. Practical Implications

### 19.1 For AI

AI systems need more than storage.

They need governed influence.

A useful system should know not only what it remembers, but how strongly that memory should affect future behaviour.

### 19.2 For Game NPCs and Simulation Agents

NPCs and simulation agents often feel flat because they do not carry meaningful retained state.

A retained-state selection layer allows prior interaction to shape future behaviour without hard-scripting every branch.

### 19.3 For Cognitive Science

The law provides a formal language for reconstructive memory, salience, interpretation, and path-dependent cognition.

### 19.4 For Philosophy of Mind

The law supports a non-mystical account of continuity:

> identity is not a static object; it is the ongoing organisation of retained state into future interpretation and action.

### 19.5 For Physics

The law may provide a future research lens for state-dependent physical systems.

But this remains speculative until supported by controlled experiments.

## 20. Final Position

Verrell's Law is not a claim that consciousness has been solved.

It is not a claim that memory floats outside the brain.

It is not a claim that CAAI proves new physics.

The current, disciplined version is stronger:

> Prior interaction can leave retained state. Retained state can act as a weighting influence. Weighted influence can alter future selection. When two systems share the same present input but differ in retained history, they may diverge in measurable ways.

That is the law.

Everything else is a possible domain application.

The immediate next step is not to over-expand the theory.

The immediate next step is to test the retained-state selection claim through controlled computational, cognitive, and engineering demonstrations.
