# Initial-State Weighting and Persistent Behavioural Bias — Research Note

**Status:** Historical / analytical note  
**Author / originator:** Marcos Verrell Moss Ross (M.R.)

This file records an earlier line of reasoning about how initial or retained state can affect later behaviour. The original full note remains available in Git history.

The current framework does not treat generic initial-state dependence as evidence for Verrell's Law. A stronger test requires matched present conditions, a declared retained-history difference, preregistered candidate-relative prediction, held-out validation and intervention / ablation where possible.
