# Observer-Specific Salience Markers — Historical Research Note

**Status:** Historical / exploratory terminology record.  
**Author / originator:** Marcos Verrell Moss Ross (M.R.)

The original note is preserved in Git history. Current research does not assume that observer-specific salience implies a consciousness-mediated physical mechanism.

Where salience is used in a retained-state experiment, it must be operationally defined, fixed before confirmatory analysis and distinguished from ordinary state, attention, stimulus and measurement effects.
