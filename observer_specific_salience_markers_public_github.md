# Observer-Specific Salience Markers

**Status:** Public research note / Measurement Forge hypothesis  
**Framework:** Verrell's Law  
**Author:** M.R. / Marcos Ross, Inappropriate Media Limited  
**Date:** 2026-06-17  

## Purpose

This note defines an observer-specific salience marker as a repeated, memory-weighted recognition pattern that may be noticed around consequential moments of thought, measurement, action, or information transfer.

This is not presented as proof of external signalling. It is a proposed logging category for Measurement Forge work.

## Core Definition

An observer-specific salience marker is not universal. It is indexed to the observer through repeated recognition, memory weighting, and timing around moments that later prove meaningful or consequential.

The marker may be numeric, verbal, symbolic, environmental, or timing-based.

## Boundary

The marker does not make an event important. The underlying event carries the weight.

A marker is only useful if it helps identify, timestamp, or later analyse a moment that may have altered a personal, project, or historical trajectory.

## Packet and Cluster Model

A salience event may be recorded as a cluster, but the cluster may represent staggered observation of a packet that has already entered the local record.

In this model:

- packet means the coherent information delivery
- cluster means the observer's later or repeated measurement of exposed parts of that delivery

## Validation Rule

A salience marker should be logged in real time where possible, but its stronger evidential value is retrospective.

The question is not whether the marker looked strange at the time.

The question is whether the linked event later proved consequential, repeatable, or measurably different from ordinary background noise.

## Measurement Notes

Useful records should include:

- date and time
- observer state
- marker type
- whether it was predicted before measurement
- whether it appeared before, during, or after the event
- linked thought, action, or information transfer
- later consequence
- misses and non-events

## Public Framing

This note avoids religious, mystical, or supernatural claims.

The working language is:

- accumulated bias
- consequence-weighted trace

## Summary Line

A salience marker does not prove the moment. It marks a moment worth logging. Consequence determines whether the moment later gains weight.
