# Verrell’s Law — A Framework for Non-Markovian Information Paths

**Author / originator:** Marcos Verrell Moss Ross (M.R.)  
**Technical edition:** Information Physics and Open Quantum Systems Framework  
**Date:** September 2026  
**Status:** Proposed theoretical model. Not established physics and not experimentally confirmed.

> **Research boundary:** This is a physics-facing technical formulation of the broader retained-state selection programme. It does not convert software behaviour, ordinary non-Markovianity, hysteresis, information erasure, or established quantum-sensing results into evidence for a new physical law.

## Core postulate

Physical evolution need not be sequence-independent. When prior interactions leave persistent, physically instantiated information, sufficiently weighted transitions may alter the effective memory through which historical states influence later dynamics and thereby bias subsequent transition probabilities.

In compact form:

```text
controlled history
→ persistent physical state / correlation
→ history-dependent memory contribution
→ altered later transition distribution
```

The distinctive question is not whether physical systems can have memory. That is already well established in many forms. The question is whether a **predeclared weighting variable** identifies an additional, reproducible, intervention-sensitive component of physical memory beyond the best conventional explanation.

## Operational weighting

A weighted transition is not defined after an unusual outcome appears, and it is not synonymous with high energy.

Candidate descriptors include predeclared combinations of:

- dissipated work;
- entropy production;
- order-parameter change;
- generated system–environment correlation;
- correlation / relaxation time;
- recurrence or resonance structure.

The coefficients, signs, time window and normalisation must be fixed before confirmatory data are inspected, or the components should remain separate.

## Non-Markovian formulation

For a reduced open system, the physics-facing proposal uses a generalized memory-kernel description. The effective kernel is treated schematically as:

```math
K_{eff}(t,\tau \mid H,W)
=
K_0(t,\tau \mid C)
+
g(w(\tau),H(\tau);\theta)K_V(t,\tau)
```

where:

- `K0` is the best supported conventional memory model under measured controls;
- `KV` is a declared candidate history-weighted structure;
- `g` specifies how prepared history and the physical weighting variable modulate that candidate structure.

A non-zero fitted memory kernel alone is **not** evidence for the proposed contribution. The additional term must improve held-out prediction, follow the preregistered weighting relation, and change appropriately under intervention on the retained history or weighting variable.

## Null hypothesis

The operative null is that the declared additional history-weighted term is absent, negligible within the preregistered equivalence region, or unnecessary once ordinary system, environment, control and instrument memory are modelled.

A negative result is informative. Measurement limitations may constrain an experiment, but lack of detection is not evidence that an undetected mechanism exists.

## Experimental routes

### Protocol A — Engineered open quantum system

Use a controllable system coupled to an engineered reservoir. Prepare different bath histories while matching the present reduced system state and declared observables within tolerance. Measure multi-time transition statistics, fit or reconstruct the registered memory model, then erase, scramble or decorrelate the prepared history.

The proposed contribution fails in the tested regime if it does not generalise, remains inside the equivalence region, or survives equally under history-scrambling and sham conditions.

### Protocol B — Field and erasure tracking

Use a known physical memory substrate such as a bistable nanostructure, resonator, quantum dot or electronic memory cell. Prepare matched final states with different controlled histories, then measure registered field, relaxation and thermal channels.

An isolated field spike, ordinary hysteresis, uncorrected drift, or heat produced by reset does not discriminate the framework from established physics.

## Integrated evidence ladder

1. **Formal identifiability** — the weighting variable, candidate kernel, null region and analysis are defined so the model can fail.
2. **Controlled history divergence** — matched present reduced states with different randomised histories produce a held-out directional difference.
3. **Intervention and ablation** — erasing, scrambling or altering the retained state changes the effect as predicted.
4. **Metrological and thermal convergence** — independent field, state and heat measurements support the same coupling timescale and direction.
5. **Independent replication** — a separate team reproduces the preregistered effect on another device and rules out the same conventional alternatives.

Established non-Markovianity is the baseline to beat, not evidence to count twice.

## Decision labels

- **Not supported** — the preregistered additional term fails its equivalence, direction or replication criteria.
- **Compatible** — a result is consistent with the framework but equally explained by established models.
- **Provisional support** — Levels 1–3 succeed with strong controls and held-out prediction.
- **Independent support** — Level 5 is reached with metrological and analytical independence.

## Claim boundary

This technical edition does **not** claim:

- an established new force or free-standing information substance;
- discovery of non-Markovian dynamics, hysteresis or Landauer heat;
- that high energy automatically means high informational weight;
- that a Mori–Zwanzig or Nakajima–Zwanzig memory kernel proves non-local memory or consciousness physics;
- a universal electromagnetic carrier;
- a universal sub-picotesla detection threshold;
- that an engineered software selector establishes a physical law.

The current scientific position is deliberately narrow: the formulation is falsifiable, but no independent experiment has yet isolated the declared history-weighted contribution.
